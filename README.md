# 線形代数2 を AI と学ぶ記録

> このリポジトリには、授業の教材の本文、問題、解答は含みません

大学のオンデマンド授業「線形代数2」を、AI（Claude）と対話しながら学んでいる記録です

授業は全15回、1回に6つのセクションがあり、全部で90セクションです

ここに置いているのは、次の4つだけです

- 学び方のルール
- 進み具合
- 学ぶ途中で自分の言葉で整理したことと、AI とのやり方の工夫
- AI が作った練習問題（授業の教材の問題ではありません）

## ファイル

| ファイル | 中身 |
|---|---|
| [HOW-I-LEARN.md](HOW-I-LEARN.md) | AI と学ぶときの進め方のルールと、そのルールができたきっかけ |
| [CLAUDE.md](CLAUDE.md) | AI が毎回読む、いちばん大事なルール（言葉づかいと、証明の書き方） |
| [PROGRESS.md](PROGRESS.md) | いま何セクション中いくつまで進んだかと、ペース |
| [JOURNAL.md](JOURNAL.md) | 日付ごとの、自分で気づいたことと、AI の失敗とその直し方 |
| [practice/](practice/) | AI が作った練習問題 4本 |

## 書かないこと

- 授業の教材の本文、図、例題や練習問題の問題文と解答
- 確認テストやレポートの中身と答え
- 教材の問題に触れるときも、番号や問題文は書きません
