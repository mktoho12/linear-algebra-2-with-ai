# AI が作った練習（第2回）：生成されるベクトル空間に入るかどうか

> この問題は、学習の途中で AI（Claude）が作ったものです
>
> 授業の教材の例題や練習問題ではありません
>
> 答えはここには書いていません

⟨v₁, v₂⟩ は「v₁, v₂ の一次結合 x₁v₁ + x₂v₂ で書けるもの全部」の集合。

## 手順

あるベクトル（や関数）w が ⟨v₁, v₂⟩ に入るかどうかは、次のように調べる。

1. w = x₁v₁ + x₂v₂ とおく（x₁, x₂ はまだわからない実数）
2. 成分ごとに比べて、x₁, x₂ についての式を作る
3. 式を全部満たす x₁, x₂ が見つかれば「入る」。どう選んでも満たせない（矛盾が出る）なら「入らない」

答えには、入る・入らないだけでなく、理由（x₁, x₂ の値や、どこで矛盾するか）も書く。

## 問題

### R³ のベクトル

v₁ = (1, 0, 2)、v₂ = (0, 1, −1)、W = ⟨v₁, v₂⟩ とする。

1. (3, 4, 2) は W に入るか。
2. (2, −1, 6) は W に入るか。
3. v₁, v₂ を列に並べた行列 A を書け。また、A に (2, −3) を右から掛けた結果を計算せよ。
4. W の要素を (a, b, c) とするとき、a, b, c が満たす式を「… = 0」の形で求めよ（W を解のなす空間として書き直す）。

### R² のベクトル

5. U = ⟨(1, 1), (1, −1)⟩ とする。(3, 1) は U に入るか。
6. U' = ⟨(1, 2), (2, 4)⟩ とする。(1, 3) は U' に入るか。

### 関数

7. 数直線上の関数全体のなすベクトル空間で、W = ⟨sin x, cos x⟩ とする。次の関数は W に入るか。
   - (a) 3 sin x − cos x
   - (b) 常に 0 を返す関数
   - (c) 2(sin x + cos x) − cos x
   - (d) sin x + 1

## ヒント

- 1〜4 は、1番目と2番目の成分を見るとすぐ x₁, x₂ が決まる形になっています
- 5 と 6 は 1〜4 と違って、x₁, x₂ がすぐには決まりません。連立方程式を解いてください。5 と 6 は答えが違います
- 6 が解けたら、「⟨2つのベクトル⟩ はいつでも R² 全部になるか？」を考えてみてください
- 7(d) は「すべての x で sin x + 1 = x₁ sin x + x₂ cos x」となる x₁, x₂ があるか、という問題です。x に具体的な数（たとえば 0 と π）を入れてみてください
