# AI が作った練習（第2回）：いろいろなベクトル空間

> この問題は、学習の途中で AI（Claude）が作ったものです
>
> 授業の教材の例題や練習問題ではありません
>
> 答えはここには書いていません

足し算・スカラー倍は、各空間のふつうのもの（成分ごと・項ごと・各点ごと）を使う。

## 問1（R³）
u = (1, −2, 3)、v = (4, 0, −1) のとき、次を計算せよ。
1. u + v
2. 2u − 3v

## 問2（2×2 行列全体）
次の A、B について計算せよ。

```
    ( 1  2 )        ( 0  -1 )
A = ( 3  4 )    B = ( 5   2 )
```

1. A + B
2. 3A − B

## 問3（実数列全体）
aₙ = n（1, 2, 3, …）、bₙ = 2ⁿ（2, 4, 8, …）とする。次の数列の最初の3項を書け。
1. a + b
2. −2a
3. a − b

## 問4（数直線上の関数全体）
f(x) = x²、g(x) = 3x − 1 とする。
1. (f + g)(2) を求めよ
2. (4f)(−1) を求めよ
3. f − g を x の式で書け

## 問5（零ベクトルと逆ベクトル）
次の空間で、零ベクトル（足しても変わらないもの）は何か。また、指定したベクトルの逆ベクトル（足すと零ベクトルになるもの）は何か。
1. R³ で、(2, −1, 5) の逆ベクトル
2. 2×3 行列全体で、次の行列の逆ベクトル

```
(  1  0  2 )
( -3  4  0 )
```

3. 実数列全体で、(1, 2, 3, …) の逆ベクトル
4. 数直線上の関数全体で、f(x) = x² の逆ベクトル

## 問6（閉じているか）
次の集合は、足し算とスカラー倍について閉じているか（外に出ないか）。閉じていないものは、外に出てしまう具体例を1つ挙げよ。
1. 平面の点 (x, y) で、x + y = 0 を満たすもの全体
2. 平面の点 (x, y) で、x + y = 1 を満たすもの全体
3. 実数列で、第1項が 0 のもの全体
4. 数直線上の関数で、f(0) = 1 を満たすもの全体
5. ちょうど2次の多項式（x² の係数が 0 でない ax² + bx + c）全体
6. 2次以下の多項式（ax² + bx + c、a = 0 も可）全体

## 問7（条件を手で確かめる）
R² で u = (u₁, u₂)、v = (v₁, v₂)、実数 a とする。成分ごとの計算で、分配法則 a(u + v) = au + av が成り立つことを確かめよ。
