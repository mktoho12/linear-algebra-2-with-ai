# AI が作った練習（第2回）：微分方程式が線形かどうか

> この問題は、学習の途中で AI（Claude）が作ったものです
>
> 授業の教材の例題や練習問題ではありません
>
> 答えはここには書いていません

f, g は未知の関数（x の関数）。f', f'', f''' はそれぞれ 1回・2回・3回微分したもの。

## 手順

1. 全部の項を左辺に移して「… = 0」の形にする
2. 左辺の項を1つずつ見て、どれも「係数 × （f を何回か微分したもの）1つ」の形になっているか確かめる
   - 係数は、数でも x の式でもよい
3. 全部の項が OK なら線形（解の集まりがベクトル空間になる）。1つでもダメな項があれば線形ではない

## 問題

次の微分方程式は線形か。線形でないものは、ダメな項を1つ挙げよ。

1. f' − 3f = 0
2. f'' + f = 0
3. f' = 5f
4. f'' − 2f = 1
5. f' + f² = 0
6. x·f' − f = 0
7. f'' + x²·f = 0
8. f' − x² = 0
9. f·f' = 0
10. (f')² − f = 0
11. f'' + sin(f) = 0
12. f'' + (sin x)·f = 0
13. eˣ·f''' − f' + 7f = 0
14. f' = f + x

## 未知の関数が2つの連立微分方程式

ルールは同じ。どの項も「係数 × （f か g のどちらか1つを何回か微分したもの）」なら線形。

15. f' − g = 0 かつ g' + f = 0
16. f' − g² = 0 かつ g' − f = 0

## ヒント

- 11 と 12、6 と 8 と 14 は、似ているけれど答えが違う組です。見比べてみてください
